## What each branch is for

G4's last clause is that no branch exists solely because a table does. A branch
is justified by the operator job it serves, not by the rows it reads, so each
group below states its job and the tree under it names what an operator does

## Depth, measured

The claim above is not an assertion about intent. `verify-admin-ia.mjs` reads the
shell's `<nav>` and fails when it stops being a flat list of links, because a
collapsible group would move its sections to two navigations and the sentence
above would become false in a file nobody re-reads.

## Changing this

Add or move a section in `apps/admin-web/src/app/config/sections.ts`, then mirror
the identity in `contracts/typescript/admin.ts`. Labels are deliberately not
compared between the two: the shell owns the words an operator reads, and a
sidebar label is shortened to fit the rail.
