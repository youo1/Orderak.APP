## Generated design system

[`design-system.default.json`](./design-system.default.json) is the canonical
compiled offline fallback generated by the pinned Worker algorithm. Do not edit
it manually. [`tokens.json`](./tokens.json) is the legacy 14-token compatibility
projection retained for old Android and older web consumers.

Runtime authority is the active immutable D1 design-system revision. Source
seeds are six-digit hex; HCT is a derived editor view. A generator upgrade
creates future snapshots only and requires a reviewed before/after publication.
Admin revision names are optional metadata: naming or renaming never changes
the snapshot or hash. Making a saved configuration current always creates a new
higher revision ID so Android ordering remains monotonic.

From `services/backend/`:

```cmd
pnpm run design-system:generate
pnpm run design-system:check
```

The check also verifies the Android fallback hash in
`ui/theme/DesignSystemContract.kt`. Approved web fonts and their license copies
are in `services/backend/assets/static/fonts/`.
