# Orderak Android App

This is the implemented Orderak seller application. It uses Kotlin, Jetpack
Compose, Hilt, Room, WorkManager, Retrofit, and Firebase Phone Authentication.
Production uses application ID `app.orderak.seller`; Staging uses
`app.orderak.seller.staging` so both can be installed together.

The UI ships with English (complete fallback), Arabic/RTL, and French resources.
Android's per-app language APIs provide explicit language selection plus a
system-default option; debug builds also expose the `en-XA` and `ar-XB`
pseudolocales for localization QA.

The protected architecture and intentional-change procedure are documented in
[`../../docs/architecture/localization-architecture.md`](../../docs/architecture/localization-architecture.md).

## Prerequisites

- Android Studio with the Android SDK and JDK 17
- `app/google-services.json` for the Production Firebase Android app
- `app/src/staging/google-services.json` for the separate Staging Firebase app
- `local.properties`, normally generated by Android Studio

See [`../../docs/guides/setup.md`](../../docs/guides/setup.md) for Firebase and backend configuration.

## Build

From this directory on Windows:

```cmd
gradlew.bat :app:assembleStagingDebug
```

The APK is written under `app/build/outputs/apk/staging/debug/`. It is labeled
**Orderak Staging** and calls `https://api.staging.orderak.app`.

For a clean diagnostic rebuild, use:

```cmd
gradlew.bat --stop
gradlew.bat clean
gradlew.bat :app:assembleStagingDebug --no-build-cache
```

## Localization verification

Compile unit tests, localization lint, and the device locale-test APK:

```cmd
gradlew.bat :app:testStagingDebugUnitTest :app:lintStagingDebug :app:assembleStagingDebugAndroidTest
gradlew.bat :app:verifyAuthPhase1Contract :app:verifyLocalizationContract :app:verifySellerApiContract
```

Run `gradlew.bat :app:connectedStagingDebugAndroidTest` when an emulator or device is
attached. The
instrumented matrix covers Arabic, English, French, `en-XA`, and `ar-XB`.

Official Compose Preview Screenshot Testing stores reviewed Arabic, English,
and French goldens under `app/src/screenshotTestDebug/reference/`:

```cmd
gradlew.bat :app:validateStagingDebugScreenshotTest
```

Only use `gradlew.bat :app:updateStagingDebugScreenshotTest` after visually reviewing
an intentional UI change; it replaces the approved reference images.

## Architecture and security

Room is the local source of truth, and WorkManager synchronizes seller data with
the Cloudflare Worker. The Android app must not call AI providers, databases, or
other protected services directly. Never put Cloudflare, Firebase server,
DeepSeek, payment, or other service secrets in the app.
